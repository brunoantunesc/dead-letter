# Dead Letter

A PSX-style murder mystery roguelite set in a hotel.

Every run presents a new murder case with procedurally generated suspects, evidence, motives, and relationships. Investigate the hotel, uncover contradictions, and identify the killer.

## Core pillars

- Procedurally generated murder mysteries
- Deduction-driven gameplay
- Interconnected suspects, motives, and evidence
- Atmospheric hotel setting
- Retro PSX visual style
- High replayability

## Status

Early development / pre-production.
